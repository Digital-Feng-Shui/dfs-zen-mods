# DFS Quiet

The next level after DFS Calm, for people who use the keyboard. Two settings in Settings > Mods > DFS Quiet.

## Settings
- **Hide buttons a shortcut covers.** Back and forward (two-finger swipe, the mouse's side buttons, Cmd [ and Cmd ]), reload (Cmd R), the sidebar button (Toggle Compact Mode, Cmd S), copy link (Cmd Shift C), reader view, and the library (Cmd Shift H for history).
- **Hide the URL bar.** The URL bar row stays closed. Cmd L opens the bar over the page, Cmd T opens it for a new tab.

Replaces the Back Fwd Always Hidden mod. The link preview setting moved to DFS Calm.
